2. Install Visual Studio Code

Windows (x64 or ARM64)

  1. Go to: https://code.visualstudio.com/download
  2. Click "Windows" to download
    • For ARM64 devices (Surface Pro X, etc.), click the arrow and select "ARM64"
  3. Run the downloaded installer (VSCodeUserSetup-xxx.exe)
  4. During installation, check these boxes:
    • ☑️ Add "Open with Code" action to Windows Explorer file context menu
    • ☑️ Add "Open with Code" action to Windows Explorer directory context menu
    • ☑️ Add to PATH (requires shell restart)
  5. Click "Install" and wait for completion
  6. Launch VS Code

macOS

Option 1 — Direct Download:

  1. Go to: https://code.visualstudio.com/download
  2. Click "Mac" (Universal build works for Intel and Apple Silicon)
  3. Open the downloaded .zip file
  4. Drag "Visual Studio Code.app" to your Applications folder
  5. Launch VS Code from Applications

Option 2 — Using Homebrew:

brew install --cask visual-studio-code

Ubuntu/Debian

Option 1 — Using snap:

sudo snap install code --classic

Option 2 — Using apt:

sudo apt update
sudo apt install software-properties-common apt-transport-https wget
wget -q https://packages.microsoft.com/keys/microsoft.asc -O- | sudo apt-key add -
sudo add-apt-repository "deb [arch=amd64] https://packages.microsoft.com/repos/vscode stable main"
sudo apt update
sudo apt install code

sudo sh -c 'echo -e "[code]\nname=Visual Studio Code\nbaseurl=https://packages.microsoft.com/yumrepos/vscode\nenabled=1\ngpgcheck=1\ngpgkey=https://packages.microsoft.com/keys/microsoft.asc" > /etc/yum.repos.d/vscode.repo'

4. Install FFmpeg

FFmpeg is required for reading and writing audio files.

Option A: Using winget (Easiest)

  1. Open PowerShell or Terminal
  2. Run: 
    winget install ffmpeg
  3. Close PowerShell completely after installation

Option B: Manual Installation

  1. Go to: https://www.gyan.dev/ffmpeg/builds/
  2. Under "Release builds", download "ffmpeg-release-essentials.zip"
  3. Extract the ZIP file
  4. Rename the extracted folder to ffmpeg
  5. Move the folder to C:\ (so you have C:\ffmpeg)
  6. Add to PATH:
    1. Press Win + X → Select "System"
    2. Click "Advanced system settings"
    3. Click "Environment Variables"
    4. Under "System variables", find "Path" and click "Edit"
    5. Click "New"
    6. Type: C:\ffmpeg\bin
    7. Click "OK" on all windows
  7. Close and reopen your terminal

Option C: Native ARM64 Build (for best performance on ARM devices)

  1. Go to: https://github.com/AnimMouse/ffmpeg-autobuild/releases
  2. Look for a file containing win-arm64 in the name
  3. Download and extract it
  4. Follow steps 4-7 from Option B above

Using Homebrew

brew install ffmpeg

Ubuntu/Debian

sudo apt update
sudo apt install ffmpeg

Fedora

sudo dnf install ffmpeg

Arch Linux

sudo pacman -S ffmpeg
✅ Verify FFmpeg Installation

Open a new terminal and run:

ffmpeg -version

You should see version information, not an error.

5. Set Up VS Code for Python

Install the Python Extension

  1. Open VS Code
  2. Click the Extensions icon in the left sidebar
    (or press Ctrl+Shift+X on Windows/Linux, Cmd+Shift+X on macOS)
  3. In the search box, type: Python
  4. Find "Python" by Microsoft (should be the first result)
    • It has a blue/yellow snake icon
    • Should show millions of downloads
  5. Click "Install"
  6. Wait for installation to complete

Verify Python is Detected

  1. Press Ctrl+Shift+P (Windows/Linux) or Cmd+Shift+P (macOS)
    This opens the Command Palette
  2. Type: Python: Select Interpreter
  3. Press Enter
  4. You should see your Python installation listed, for example:
    • Python 3.12.0 ('python')
    • Python 3.14.0 64-bit
  5. Click on your Python version to select it
💡 No Python appearing?
  • Restart VS Code
  • Make sure Python was installed with "Add to PATH" checked
  • See Troubleshooting section

6. Create the Project

1 Create Project Folder

Create a new folder anywhere you like:

  • Windows: C:\Users\YourName\Documents\CRT-Audio
  • macOS: ~/Documents/CRT-Audio
  • Linux: ~/Documents/CRT-Audio

2 Open Folder in VS Code

Option 1 — From VS Code:

  1. Open VS Code
  2. Click File → Open Folder
  3. Navigate to your CRT-Audio folder
  4. Click "Select Folder"

Option 2 — From File Explorer/Finder:

  1. Right-click on your CRT-Audio folder
  2. Select "Open with Code"

3 Create the Script File

  1. In VS Code, look at the Explorer panel on the left
    (if not visible, click the top icon or press Ctrl+Shift+E)
  2. Hover over the folder name "CRT-AUDIO" in the Explorer panel
  3. Click the "New File" icon (page with a plus sign)
  4. Type: crt_tv_audio.py
  5. Press Enter
  6. The file opens in the editor

4 Paste the Script Code

  1. Copy the entire Python script (provided separately)
  2. In VS Code, click inside the empty crt_tv_audio.py file
  3. Paste the code:
    • Windows/Linux: Ctrl+V
    • macOS: Cmd+V
  4. Save the file:
    • Windows/Linux: Ctrl+S
    • macOS: Cmd+S

5 Add Your Audio File

  1. Find your MP3 file in File Explorer/Finder
  2. Copy it to your CRT-Audio folder
  3. Rename it to: input.mp3
    (or change INPUT_FILENAME in the script to match your filename)

6 Verify Project Structure

Your VS Code Explorer panel should show:

CRT-AUDIO/
├── crt_tv_audio.py
└── input.mp3

7. Install Python Packages

Open the Integrated Terminal

  1. In VS Code, open the terminal:
    • Windows/Linux: Press Ctrl+` (backtick, below Escape key)
    • macOS: Press Cmd+`
    • Or click: View → Terminal
  2. The terminal opens at the bottom of VS Code
  3. Make sure you're in your project folder — the prompt should show your folder path

Install NumPy and SciPy

In the VS Code terminal, type the following and press Enter:

Windows:

pip install numpy scipy

macOS/Linux:

pip3 install numpy scipy

You should see output like:

Collecting numpy Downloading numpy-2.0.0-cp312-... Collecting scipy Downloading scipy-1.14.0-cp312-... Successfully installed numpy-2.0.0 scipy-1.14.0

Verify Installation

In the terminal, run:

python -c "import numpy; import scipy; print('Packages OK')"

Should print: Packages OK

8. Run the Script

Method 1: Using the Play Button (Easiest)

  1. Make sure crt_tv_audio.py is open in the editor
  2. Look at the top-right corner of VS Code
  3. Click the "Play" button (triangle icon)
    • If you see a dropdown arrow, click the triangle, not the arrow
  4. The script runs in the terminal at the bottom

Method 2: Using the Terminal

  1. Open the integrated terminal (Ctrl+`)
  2. Run: 
    python crt_tv_audio.py
    Or on macOS/Linux: 
    python3 crt_tv_audio.py

Method 3: Using Run and Debug

  1. Press F5
  2. If prompted, select "Python File"
  3. The script runs with debugging enabled
  4. You can set breakpoints by clicking left of line numbers

Method 4: Right-Click Context Menu

  1. Right-click anywhere in the crt_tv_audio.py editor
  2. Select "Run Python File in Terminal"

9. Customizing the Sound

Editing the Script in VS Code

  • Open crt_tv_audio.py in the editor
  • Use Ctrl+G (or Cmd+G) to "Go to Line"
  • Use Ctrl+F to find specific settings

Input/Output Files

INPUT_FILENAME = "input.mp3"        # Your source file
OUTPUT_FILENAME = "output_crt_tv.mp3"  # Output file name

Lo-Fi Quality (Sample Rate)

TARGET_SAMPLE_RATE = 16000
Value Effect
8000Extreme lo-fi (tiny TV, very muffled)
11025Heavy lo-fi (small TV)
16000Standard lo-fi (default, 1960s TV)
22050Mild lo-fi (1970s console TV)
32000Light effect (1980s TV)

TV Speaker EQ

TV_SOUND = {
    "output_gain_db": -2.0,       # Final volume (-6 quieter, 0 louder)
    "band_low_hz": 150.0,         # Cut bass below this (higher = thinner)
    "band_high_hz": 4500.0,       # Cut treble above this (lower = muffled)
    "low_mid_split_hz": 300.0,    # Where "low" ends and "mid" begins
    "mid_high_split_hz": 3000.0,  # Where "mid" ends and "high" begins
    "low_gain_db": -8.0,          # Bass cut (more negative = less bass)
    "mid_gain_db": +1.5,          # Midrange boost (voice clarity)
    "high_gain_db": -12.0,        # Treble cut (more negative = duller)
}

Noise Settings

NOISE = {
    "hiss_level_db_rel": -32.0,   # Tape hiss (-20 loud, -40 subtle, None off)
    "hum_level_db_rel": -38.0,    # 60Hz hum (-25 loud, -45 subtle, None off)
    "hum_frequency_hz": 60.0,     # 60 for US, 50 for Europe
    "hum_harmonics": 3,           # More = buzzier hum
}

Distortion Settings

DISTORTION = {
    "drive_db": 6.0,    # Overdrive amount (0 clean, 12 crunchy)
    "mix": 0.7,         # Blend (0.0 none, 0.5 half, 1.0 full distortion)

10. Troubleshooting

❌ "Python" not found / No interpreter selected

Symptom: VS Code shows "Select Python Interpreter" or script won't run.

Fix:

  1. Press Ctrl+Shift+P
  2. Type: Python: Select Interpreter
  3. Press Enter and select your Python version

If no Python appears: Close VS Code, reinstall Python with "Add to PATH" checked, restart computer.

❌ "ffmpeg" is not recognized

Symptom: Script shows "ERROR: ffmpeg is required but was not found."

Fix:

  1. Close VS Code completely
  2. Open a NEW PowerShell/Terminal window (not in VS Code)
  3. Run: ffmpeg -version
  4. If it fails, reinstall FFmpeg (see Section 4)
  5. Restart your computer
  6. Reopen VS Code and try again
❌ ModuleNotFoundError: No module named 'numpy'

Symptom: Import error when running the script.

Fix:

  1. Open VS Code terminal (Ctrl+`)
  2. Run: pip install numpy scipy
  3. If that fails, try: python -m pip install numpy scipy
  4. Restart VS Code
❌ "pip" is not recognized

Symptom: Terminal says pip is not found.

Fix for Windows:

python -m pip install numpy scipy

Fix for macOS/Linux:

python3 -m pip install numpy scipy

If still failing:

python -m ensurepip --upgrade
❌ Input file not found

Symptom: "ERROR: Input file not found"

Fix:

  1. Check that input.mp3 is in the SAME folder as the script
  2. Check the filename matches exactly (case-sensitive on macOS/Linux)
  3. Look at the Explorer panel — both files should be visible
  4. Update INPUT_FILENAME in the script to match your actual filename
❌ Permission denied

Symptom: Cannot write output file.

Fix for Windows: Right-click VS Code → "Run as Administrator"

Fix for macOS/Linux: Check folder permissions with ls -la

❌ Output sounds wrong

Too quiet: Change output_gain_db from -2.0 to 0.0 or +2.0

Clipping/too loud: Change output_gain_db to -4.0 or -6.0

Too much noise: Set hiss_level_db_rel to -40.0 or None

❌ Play button missing

Symptom: No triangle/play button in top-right corner.

Fix:

  1. Make sure Python extension is installed
  2. Make sure a .py file is open in the editor
  3. Click on the file tab to make it active
  4. Or press Ctrl+Shift+P, type "Python: Run Python File"
